# FND Studio

7-세그먼트(FND) 디코더 실습을 위한 도구입니다. 한 페이지에서 **설계 · 검증 · 채점**을 합니다.
MyLogic 시뮬레이션 결과(`mysim.out`)를 읽고, 설치나 서버 없이 브라우저에서만 동작합니다.

**바로 쓰기**: https://caffentrager.github.io/fnd-studio/  (파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.)

| 탭 | 하는 일 |
|---|---|
| **설계** | 16자리 FND를 직접 만들고, 진리표와 카르노 맵(묶음·간소화 식)으로 본다 |
| **검증** | `mysim.out` 하나를 열어 만든 FND(또는 표준 BCD/Hex)와 비교하고 전체 출력·진리표·타이밍 파형을 본다 |
| **채점** | 여러 학생의 `.out`(또는 폴더째)을 한 번에 만든 FND와 비교해 통과/불일치를 표로 본다 |

설계 탭에서 만든 FND는 검증·채점 탭의 기준이 되며, 고치면 두 탭에 바로 반영됩니다.

## 설계

1. 빈 FND 16칸이 나타납니다. 각 칸은 입력 `W X Y Z`(W가 최상위 비트) 한 가지(0~F)에 대응합니다.
2. 세그먼트를 누를 때마다 **꺼짐 → 켜짐 → X(돈케어) → 꺼짐** 순으로 바뀌고, **진리표**(W X Y Z → A~G)와 **카르노 맵**(A~G 7개)이 바로 갱신됩니다. 맵의 행은 `W X`, 열은 `Y Z`이며 그레이 코드 순서입니다.
3. 각 FND 칸 오른쪽 위의 **X 버튼**은 그 FND 전체를 X(돈케어)로 바꾸고, 다시 누르면 비웁니다.
   **FND 칸을 선택한 뒤 `0`–`9`, `A`–`Z`를 누르면 그 글자 모양으로 자동 전환**됩니다. 물리 키로 읽기 때문에 한글 입력 상태에서도 동작합니다.
   - `0`~`F`는 표준 모양이고, `G H I J L N O P Q R S T U Y Z -(하이픈) _(Shift+하이픈)`도 7-세그먼트 모양으로 바뀝니다. `K M V W`는 표현할 수 없어 안내만 합니다.
   - `X`는 돈케어, `Backspace`/`Delete`는 지우기, `←` `→`는 선택한 칸 이동입니다.
4. 카르노 맵에는 **묶음**이 색깔별 둥근 도형으로 그려지고, 같은 색의 항으로 간소화한 식(`A = W̄Z + W̄Y + …`)이 아래에 나옵니다.
   - 가장자리를 넘어 이어지는 묶음은 양쪽 끝이 열린 모양으로 그려집니다.
   - 돈케어(X)는 묶음에 도움이 될 때만 사용하고, 반드시 덮지는 않습니다.
   - 항 수가 가장 적고, 같으면 리터럴이 가장 적은 식을 구합니다. 최적의 식이 여러 개면 후보 식이 모두 나열되고, 하나를 고르면 그 식의 묶음만 색으로 그려집니다.
   - 한 맵 안의 묶음은 모두 서로 다른 색입니다. (라이트/다크 테마별로 색을 따로 정했습니다.)
   - `SoP · 1 묶기`(곱의 합)와 `PoS · 0 묶기`(합의 곱)를 전환할 수 있습니다.
5. 칸·표·맵 어디서든 입력을 선택하면 세 곳에서 함께 강조됩니다.
6. `BCD 0–9 채우기`(10~15는 X) / `Hex 0–F 채우기`로 표준 모양에서 시작하거나, `전체 지우기`로 비울 수 있습니다.
7. `CSV 복사`, `.out 저장`으로 내보내고, `검증 탭에서 보기`로 지금 모양 자체의 파형·판정을 봅니다.

만든 모양과 묶는 방식은 이 브라우저에 자동 저장됩니다.

## 검증

`mysim.out`을 **파일 열기**로 고르거나 화면에 끌어다 놓습니다. 같은 폴더의 `vhdl` 파일을 함께 놓으면 입력 신호를 정확히 구분합니다. 파일이 없으면 **데모**로 둘러볼 수 있습니다.

- **검증 기준**: **만든 FND** / BCD 0–9 / Hex 0–F / 끄기
  - **만든 FND**: 설계 탭에서 만든 모양과 정확히 비교합니다. 돈케어(X)로 둔 세그먼트는 어떤 값이어도 통과합니다. VECTOR가 없는 파일도 입력 4개를 추정해 판정합니다.
  - BCD/Hex: 표준 모양과 비교하며 1(좌/우), 6·7·9(획 유무), A(대/소문자), C(대/소문자) 변형을 인정합니다.
- **출력 검증**: `다음 출력 확인`을 누를 때마다 다음 입력으로 넘어가며, 틀린 세그먼트는 `A B C D E F G` 글자와 점선으로 표시됩니다.
- **전체 출력**: 모든 입력의 7-세그먼트를 한눈에 보고, 문제 세그먼트별 요약(`G 2건 · 입력 8, C`)을 제공합니다. 칸이 96개를 넘으면 일부만 그리고, 나머지에 불일치가 몇 개 있는지 알려 주며 `나머지 모두 보기`로 펼칩니다.
- **진리표**: 입력 열을 앞으로 모으고, 입력값을 10진수와 16진수로 함께 보여줍니다. 반복되는 행은 접을 수 있습니다.
- **타이밍 파형**: 신호별 파형과 버스 값을 보여주며 Ctrl+휠로 확대/축소합니다.
- **다시 읽기 / 변경 자동 감지**: 시뮬레이션을 다시 돌리면 결과가 자동으로 갱신됩니다. (Chrome/Edge)
- 키보드: `←` `→` `Space` `Home` `End`

## 채점

`.out` 파일 여러 개 또는 **폴더째** 끌어다 놓거나 `파일 선택`/`폴더 선택`을 누릅니다. 폴더 안쪽의 `.out`을 모두 찾아 채점하고, 파일 이름은 `폴더/파일` 경로로 표시합니다.

- 입력값(0~F)마다 **안정된 출력**(입력이 다음 값으로 바뀌기 직전의 마지막 행)이 만든 FND와 맞아야 **일치**입니다. 입력이 바뀐 직후의 과도 상태 때문에 정상 회로가 불합격이 되지 않게 하기 위해서이며, 채점 방식을 **모든 행 엄격 채점**으로 바꾸면 그 입력이 나온 모든 행을 봅니다.
- 한 번도 안 나온 입력은 **누락**이고(전부 돈케어인 입력은 제외), 불일치·누락이 하나라도 있으면 **불일치**입니다. 틀린 입력은 행의 시간과 기대/실제 출력까지 펼쳐 볼 수 있습니다.
- **입력 신호 확인**: 입력은 파일의 `VECTOR`가 있으면 그것을, 없으면 A–G를 뺀 4개 신호(파일 순서) 또는 값 패턴으로 **추정**합니다. 표의 `입력 신호` 열에 어떤 신호를 입력으로 썼는지 나오고, 추정한 파일은 `입력 추정` 필터로 모아 볼 수 있습니다. VECTOR가 4비트가 아니면 오류로 분류합니다.
- **만든 FND가 비어 있으면 채점을 보류**(`대기`)합니다. 모든 출력이 꺼진 파일이 통과로 나오는 것을 막기 위해서이고, 의도한 경우에는 `빈 FND로 그래도 채점`을 누릅니다.
- 형식 오류, A–G 신호 없음, 입력 신호를 알 수 없는 경우는 **오류**로 이유와 함께 분류됩니다.
- 결과는 전체/통과/불일치/오류로 거르고, 이름순 또는 틀린 칸 많은 순으로 정렬할 수 있습니다.
- 파일마다 `검증 탭에서 열기`로 틀린 세그먼트와 파형을 자세히 볼 수 있습니다.
- `CSV 복사` / `CSV 저장`(엑셀에서 한글이 깨지지 않도록 BOM 포함)으로 내보냅니다.
- 설계 탭에서 만든 FND를 고치면 채점 탭으로 돌아올 때 자동으로 다시 채점합니다.

## 샘플

[`samples/`](samples)에 바로 열어볼 수 있는 결과 파일이 있습니다.

| 파일 | 내용 |
|---|---|
| `fnd.out` (+ `fnd.vhdl`) | BCD → 7-세그먼트 디코더. 모두 정상 |
| `fnd-error.out` | 위와 같지만 8은 G가, 9는 B·C가 꺼져 있는 **오류 예제** (검증·채점 기능 확인용) |
| `fa.out` | 전가산기 (A–G가 없어 채점에서는 오류로 분류됨) |
| `adder2bit.out` | 2비트 가산기 |
| `xor3-parity.out` | 3입력 XOR 패리티 |

설계 탭에서 `BCD 0–9 채우기`를 누른 뒤 채점 탭에 `fnd.out`과 `fnd-error.out`을 함께 올려 보세요. (`fnd.out`의 7은 F가 켜진 모양이라 7의 F를 돈케어로 바꿔야 통과합니다.)

## 파일 형식

```
[MySim Result V3.5]
MAX_TIME 1000;
VECTOR <이름> W X Y Z;
WATCH A B C D E F G W X Y Z <이름>;
TABLE_ORDER A B C D E F G W X Y Z;
START
0 11111100000
10 01100000001
...
END
```

CP949(한글 Windows) 인코딩도 자동으로 읽습니다.

## 구조

빌드 과정이 없고 외부 라이브러리를 쓰지 않는 정적 페이지입니다. 폴더째 두어야 합니다.

```
index.html           세 탭의 화면
css/common.css       토큰 · 기본 요소 · 표 · 7-세그먼트         js/common.js    유틸 · 표준 모양 · 만든 FND 저장 · 테마
css/designer.css     설계 탭 (FND 편집기 · 카르노 맵)           js/designer.js  설계 탭
css/viewer.css       검증 탭                                    js/viewer.js    검증 탭 (파서 · 판정 · 파형)
css/studio.css       채점 · 탭 패널                             js/grader.js    채점 탭
                                                                js/studio.js    탭 전환 · 탭 사이 연결
```

스크립트·스타일 주소 끝의 `?v=…`는 배포 직후 오래된 캐시가 새 HTML과 섞이지 않게 하는 값이니, 코드를 고쳐 배포할 때 같이 올려 주세요.
